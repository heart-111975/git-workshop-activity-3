**Brief Description:**
This is a simple HTML project created to demonstrate the basic use of Git. It shows how to create a repository, save different versions, and view the project history.

**Reflection:**
The `git add` command stages the changes that I want to include in the next version. The `git commit` command permanently records the staged changes in the Git history. In simple terms, `git add` prepares the changes, while `git commit` saves them as a version.
